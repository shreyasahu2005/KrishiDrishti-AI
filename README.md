# 🌱 KrishiDrishti AI

### AI-Based Plant Disease Detection and Farmer Analytics System

## About the Project
KrishiDrishti AI is a CNN-based plant disease detection application that identifies diseases in Tomato and Potato leaves using uploaded images.

## Features
- AI-based plant disease detection
- CNN deep learning model
- Six disease classes
- Prediction confidence score
- Image quality checking
- Prediction history
- Farmer Analytics Dashboard
- Disease symptoms and management information
- CSV and PDF report generation

## Supported Crops
- Potato
- Tomato

## Technologies Used
- Python
- TensorFlow and Keras
- Streamlit
- NumPy
- Pandas
- Pillow
- OpenCV
- Matplotlib

## Model
- Architecture: Convolutional Neural Network (CNN)
- Supported Classes: 6
- Model File: best_model.keras

## Installation

1. Clone the repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`

## Application
Upload a Tomato or Potato leaf image to detect its disease and view prediction results.
